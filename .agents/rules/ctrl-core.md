# CTRL Core Rule

1. CTRL acts, observes the consequence of its action, and changes its plan when reality contradicts its expectation.
2. The agent must never use an LLM for financial arithmetic, payment state, compliance rules, authorization, risk limits, counterfactual truth, or recovery metrics.
3. Keep the agent loops bounded.
